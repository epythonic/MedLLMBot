Ce este această secțiune

Aceasta este memoria botului. Fiecare schimb obișnuit „întrebarea clientului — răspunsul botului” se salvează aici. La următoarea întrebare botul îi transmite lui Claude ultimele mesaje ale acestui client, iar modelul își amintește despre ce a fost vorba. Adâncimea istoricului din {{ section_link('bot-config') }} stabilește câte mesaje se transmit.

Ce nu ajunge aici

  • Mesajele suspecte și răspunsurile în care modelul a încercat să-și dezvăluie regulile — ca atacul să nu se acumuleze în memoria botului.
  • Mesajele prea lungi, mesajele clienților blocați și cele omise pentru că clientul a scris prea des.
  • Întrebările la care Claude nu a răspuns din cauza unei erori.

Toate acestea se află în {{ section_link('audit-event') }} — acolo este înregistrat fiecare mesaj primit.

Cum citiți dialogul unui client

  1. Aflați Chat ID-ul clientului: îl găsiți în {{ section_link('client') }}, în cerere și în jurnal.
  2. În blocul Filtre, alegeți pentru Chat ID condiția Egal cu, introduceți numărul și apăsați Aplicați filtrul.
  3. Mesajele sunt afișate de la cele mai noi. user — clientul, assistant — botul.

Prin ce diferă conversațiile de jurnal

ConversațiiMemoria botului pentru Claude. Doar mesajele care au trecut verificările și doar ceea ce a primit clientul. Se păstrează pe termen nelimitat.
JurnalToate mesajele primite: rezultatul procesării, răspunsul inițial al modelului, tokenurile și costul. Se păstrează atâtea zile câte sunt indicate în setări.
{% call note("info", "Doar citire") %} Conversațiile nu pot fi modificate sau șterse din panoul de administrare: sunt datele de bază pe care se sprijină botul. {% endcall %}
