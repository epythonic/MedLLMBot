Cum citiți raportul

  • Un card — o lună, cele mai noi sus. În antetul cardului — suma pe lună.
  • Rândurile sunt modele, cele mai scumpe sus. Ultimul rând, „Total”, este suma pentru toate modelele.
  • Pentru luna curentă, lângă sumă este afișată prognoza pe lună: suma cheltuită se împarte la zilele trecute și se înmulțește cu numărul de zile din lună. În primele zile ale lunii prognoza este aproximativă.
  • Lunile se calculează după UTC, ca în facturile Anthropic.

Este o estimare, nu o factură

Raportul se calculează după tokenurile din răspunsurile lui Claude și prețurile din {{ section_link('model-price') }}. Taxele, reducerile contractuale și solicitările către API făcute în afara botului nu sunt luate în calcul. Suma exactă o găsiți în Anthropic Console, în secțiunea Usage / Cost.

{% call note("warning", "Avertismentul despre solicitările fără preț") %} Dacă sub tabelul lunii există un avertisment despre solicitări fără preț, totalul este subestimat: adăugați modelul în {{ section_link('model-price') }}. {% endcall %}

Cum reduceți cheltuielile

  • Modelul. Haiku este de câteva ori mai ieftin decât Sonnet și Opus și se descurcă bine cu întrebările din baza de cunoștințe.
  • Adâncimea istoricului din {{ section_link('bot-config') }}: fiecare mesaj din istoric adaugă tokenuri la fiecare întrebare a clientului.
  • Dimensiunea bazei de cunoștințe. Ea se trimite cu fiecare întrebare. Cache-ul ieftinește repetările, dar este mai bine să dezactivați secțiunile inutile și serviciile inactive.
