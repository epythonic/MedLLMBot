La ce folosește această secțiune

Secțiunea pregătește demo-ul pentru prezentare fără acces la server. Butoanele fac același lucru ca și comanda seed --reset:

  • Reîmprospătați demo-ul — readuce afacerea curentă la starea inițială. Datele conversațiilor fictive se numără de la momentul apăsării, așa că {{ section_link('analytics') }} le arată din nou pentru ultima săptămână.
  • Comutați la „…” — arată cealaltă afacere: clinica stomatologică sau magazinul de electronice. Se schimbă profilul botului, baza de cunoștințe, salutul și clienții fictivi.

Înainte de resetare browserul cere confirmarea. După aceea pagina arată ce demo este deschis acum.

Ce se șterge și ce rămâne

  • Se șterg toți clienții, conversațiile, cererile, comenzile și înregistrările din jurnal — inclusiv cele reale, dacă cineva i-a scris botului în timpul prezentării. Modificările dvs. în baza de cunoștințe, prețurile modelelor și setările botului se resetează și ele.
  • Se restabilesc baza de cunoștințe demo, prețurile modelelor, setările botului și clienții fictivi cu conversații, cereri în toate statusurile și jurnalul pe o săptămână.
  • Rămân {{ section_link('admin-user') }}, totalurile din {{ section_link('usage-daily') }} și limita zilnică de cheltuieli din {{ section_link('bot-config') }}.
{% call note("warning", "Doar pentru serverul demo") %} Secțiunea este vizibilă doar dacă pe server este activată setarea ADMIN_DEMO_TOOLS=true. În panoul de administrare al unei afaceri reale ea nu se activează: un singur buton i-ar șterge clienții și cererile. {% endcall %}
