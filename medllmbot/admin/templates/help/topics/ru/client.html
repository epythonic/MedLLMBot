Откуда берутся клиенты

Клиент появляется здесь, как только впервые пишет боту. При каждом следующем сообщении бот обновляет его имя, username и время Последнего сообщения. Добавить или удалить клиента вручную нельзя: вместе с ним пропали бы переписка и заявки.

Как заблокировать клиента

  1. Найдите клиента: строка поиска ищет по Chat ID, username и имени. Chat ID удобно скопировать из {{ section_link('audit-event') }} или из заявки.
  2. Нажмите значок карандаша в строке клиента.
  3. Отметьте Заблокирован и нажмите Сохранить.

Быстрее — прямо из {{ section_link('audit-event') }}: на странице записи рядом с Chat ID есть кнопка Заблокировать клиента. Чтобы разблокировать, снимите отметку здесь или нажмите Разблокировать на странице записи журнала. Изменение действует со следующего сообщения клиента, перезапускать бота не нужно.

Что происходит с заблокированным клиентом

  • Бот молча перестаёт отвечать. Клиент не получает сообщения о блокировке.
  • Claude не вызывается, поэтому сообщения заблокированного клиента ничего не стоят.
  • Заявки из его сообщений не создаются.
  • Каждое сообщение всё равно попадает в {{ section_link('audit-event') }} с итогом «Клиент заблокирован» — видно, продолжает ли он писать.

Когда блокировать

Спам, оскорбления, повторяющиеся попытки взломать бота (в журнале много записей с отметкой Подозрительное). Фильтр Заблокирован справа показывает всех заблокированных.

{% call note("warning", "Одна подозрительная фраза — не повод") %} Детектор атак иногда ошибается. Прежде чем блокировать, откройте журнал клиента и убедитесь, что это не обычный вопрос, сформулированный необычно. {% endcall %}

Живой оператор

Клиент может попросить человека вместо бота: «позовите менеджера», «хочу поговорить с человеком», «vreau să vorbesc cu un om» или команда /operator. Тогда:

  1. Бот отвечает клиенту, что передал вопрос, и вы получаете в Telegram уведомление с последними сообщениями диалога и кнопкой Вернуть бота. Уведомление получают и сотрудники из {{ section_link('staff-member') }}: клиента ведёт тот, кто ответил первым, остальным бот пишет, кто его взял.
  2. Пока диалог у вас, бот в этом чате молчит: сообщения клиента, включая фото и голосовые, приходят вам, Claude не вызывается. В колонке С оператором до видно, до какого времени.
  3. Чтобы ответить, ответьте в Telegram (свайп или «Ответить») на сообщение бота об этом клиенте: уведомление, пересланное сообщение или уведомление о его заявке. Текст, фото или файл уйдёт клиенту, а на вашем сообщении появится 👍. Каждый ответ продлевает срок; ответ на старое уведомление снова включает режим оператора. Сообщение, написанное боту просто в чат, без ответа, клиенту не уходит: пока клиенты ждут оператора, бот вместо ответа напомнит, как ответить, и покажет кнопку Вернуть бота для каждого из них.
  4. Закончили — нажмите Вернуть бота: клиент получит сообщение, что дальше снова отвечает бот. Если не ответить совсем, бот вернётся сам через срок из {{ section_link('bot-config') }}. Клиент может вернуться к боту и сам — командой /start; вы получите об этом сообщение.
{% call note("info", "Переписка с оператором") %} Сообщения клиента и ваши ответы сохраняются в {{ section_link('chat-message') }}: вернувшись, бот знает, о чём шла речь. В {{ section_link('audit-event') }} они видны с итогами «Позвал оператора», «Переслано оператору» и «Ответ оператора». Исправления, которые клиент вносит в уже отправленные сообщения, не пересылаются. {% endcall %} {% call note("warning", "Только личный чат администратора") %} Отвечать клиентам может только администратор из настройки ADMIN_ID — ответом из своего личного чата с ботом. Если там указана группа, просьбу позвать человека бот обрабатывает как обычный вопрос. Ваши собственные сообщения боту без ответа на уведомление бот обрабатывает как вопросы клиента — так удобно его проверять. {% endcall %}
