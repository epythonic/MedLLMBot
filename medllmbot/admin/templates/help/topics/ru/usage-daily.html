Что здесь

Одна строка — один день и одна модель. Каждый запрос к Claude бот добавляет в строку своего дня одновременно с записью в {{ section_link('audit-event') }}, поэтому итоги всегда сходятся с журналом.

  • Дни считаются по UTC, как в счетах Anthropic.
  • Строки не содержат персональных данных и не удаляются вместе со старыми записями журнала: по ним можно посчитать расходы за любой период.
  • Раздел только для чтения — итоги пишет бот.

Колонка «Без цены»

Сколько запросов за день выполнено моделью, для которой нет цены в {{ section_link('model-price') }}. Стоимость таких запросов не учтена, итог дня занижен. Добавьте цену — следующие запросы посчитаются, прошлые останутся без стоимости.
