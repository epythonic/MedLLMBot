Как читать отчёт

  • Одна карточка — один месяц, новые сверху. В заголовке карточки — сумма за месяц.
  • Строки — модели, самые дорогие сверху. Последняя строка «Итого» — сумма по всем моделям.
  • Для текущего месяца рядом с суммой показан прогноз на месяц: потраченное делится на прошедшие дни и умножается на число дней в месяце. В первые дни месяца прогноз грубый.
  • Месяцы считаются по UTC, как в счетах Anthropic.

Это оценка, а не счёт

Отчёт считается по токенам из ответов Claude и ценам из {{ section_link('model-price') }}. Налоги, скидки по договору и запросы к API в обход бота не учитываются. Точную сумму смотрите в Anthropic Console, в разделе Usage / Cost.

{% call note("warning", "Предупреждение «без цены»") %} Если под таблицей месяца есть предупреждение о запросах без цены, итог занижен: добавьте модель в {{ section_link('model-price') }}. {% endcall %}

Как снизить расходы

  • Модель. Haiku в разы дешевле Sonnet и Opus и хорошо справляется с вопросами по базе знаний.
  • Глубина истории в {{ section_link('bot-config') }}: каждое сообщение истории добавляет токены к каждому вопросу клиента.
  • Размер базы знаний. Она отправляется с каждым вопросом. Кэш удешевляет повторы, но лишние разделы и неактивные услуги лучше отключать.
