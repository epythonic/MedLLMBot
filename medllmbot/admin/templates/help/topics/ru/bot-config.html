Как изменить настройки

Настройки — одна строка. Нажмите значок карандаша, измените поля и нажмите Сохранить. Бот применит изменения к следующему сообщению клиента, перезапускать его не нужно.

Профиль бизнеса

Профиль определяет, кем представляется бот и какие предметные правила соблюдает:

  • Стоматология — не ставит диагнозы, при острой боли советует прийти на приём, записывает на приём.
  • Магазин электроники — помогает выбрать технику под бюджет и задачи, не обещает наличие и сроки доставки, которых нет в базе знаний, оформляет заказ через менеджера.

Правила безопасности одинаковые для обоих профилей. Профиль меняется вместе с базой знаний командой на сервере, поэтому в форме его нет:

docker compose run --rm migrate python -m medllmbot.db.seed --reset --profile shop
{% call note("warning", "Сброс удаляет данные демо") %} Команда удаляет клиентов, переписку, заявки и журнал и заменяет базу знаний демо-данными профиля. Итоги расходов и дневной лимит остаются. Обратно на стоматологию — --profile clinic. {% endcall %}

Как сменить модель Claude

  1. Добавьте новой модели цену в {{ section_link('model-price') }}: без неё настройки не сохранятся — так админка заодно ловит опечатки в ID модели.
  2. Впишите ID модели в поле Модель, например claude-haiku-5-5, и сохраните.
  3. Напишите боту тестовый вопрос.
  4. Откройте {{ section_link('audit-event') }}: у последней записи итог должен быть «Ответ», а стоимость — не «—».
{% call note("danger", "Ошибка в ID модели остановит ответы") %} Если в журнале итог «Ошибка API», модель указана неверно (например, у неё есть цена, но такой модели нет у Anthropic): клиенты получают извинение вместо ответа. Сразу верните прежнее значение. {% endcall %}

Лимиты

  • Лимит токенов ответа ограничивает длину ответа бота, а не вопроса клиента. Ответы бота короткие, 1024 хватает с запасом. Если ответ не помещается в лимит, бот не отправляет клиенту обрывок, а отвечает «Уточню у администратора» и пишет в журнал итог «Ответ обрезан». Видите такие записи — увеличьте лимит.
  • Макс. длина сообщения клиента — в символах. Более длинные сообщения отсекаются до обращения к Claude: это защита от спама и лишних расходов. Клиент получает ответ с цифрами: «Сообщение слишком длинное: 1350 символов, а можно не больше 1024. Пожалуйста, напишите вопрос короче.» Если в сообщении есть телефон, заявка всё равно создаётся, а клиент узнаёт, что номер сохранён.
  • Глубина истории — сколько последних сообщений диалога видит модель. 0 — бот не помнит разговор; 8 — хватает для обычной записи на приём. Больше — дороже каждый ответ.
  • Сообщений в окне и Окно rate-limit: по умолчанию не больше 10 сообщений за 60 секунд от одного клиента. Лишние сообщения бот молча пропускает и отмечает в журнале итогом «Rate-limit».

Готовые ответы без Claude — «Уточню у администратора», «Сообщение слишком длинное», извинение за ошибку и другие — бот пишет на языке сообщения клиента: по-русски или по-румынски. Если по тексту язык не понять (команда, номер заказа, фото без подписи), бот берёт язык из настроек Telegram клиента. Приветствий два — о них ниже.

Лимит расходов в сутки

Бот открыт любому пользователю Telegram. Ограничение по сообщениям действует на каждого клиента отдельно, а Лимит расходов в сутки — на всех вместе: когда расходы на Claude за текущие сутки (UTC) достигают лимита, бот до полуночи UTC отвечает «Администратор ответит вам в рабочее время», не обращаясь к модели. Заявки с телефоном сохраняются как обычно, вы получаете уведомление в Telegram (не чаще раза в 6 часов), а в {{ section_link('audit-event') }} появляется итог «Лимит расходов».

  • 0 — лимита нет.
  • Для демо достаточно 1–2 долларов: один ответ claude-haiku-5-5 стоит доли цента.
  • Считаются только запросы с ценой в {{ section_link('model-price') }}: модель без цены лимит не расходует.

Каталог в промпте

Пока активных услуг в {{ section_link('service') }} не больше этого числа, бот передаёт Claude весь прайс с каждым вопросом. Если услуг больше, бот не передаёт весь прайс, а ищет в нём нужные позиции. Подробнее — в справке раздела {{ section_link('service') }}.

  • 50 (по умолчанию) подходит клинике: весь прайс в запросе — самый быстрый и дешёвый ответ. В демо магазина 64 позиции, поэтому там бот ищет в каталоге.
  • 0 — бот всегда ищет. Так можно показать поиск на маленьком каталоге.
  • Проверка цен работает в обоих режимах: бот не назовёт цену, которой нет в каталоге.

Приветствие и журнал

  • Приветствие (/start) — первое, что видит клиент. Коротко: кто вы, чем бот поможет, как записаться.
  • Приветствие по-румынски — то же для клиентов с Telegram на румынском. В «/start» нет текста, по которому понять язык, поэтому бот смотрит на язык Telegram: на русском — русское приветствие, на румынском — румынское, на любом другом — оба подряд (многие пишут по-румынски из Telegram на английском). Оставьте поле пустым, если в первом приветствии уже есть оба языка: тогда его получают все.
  • Хранить журнал, дней — срок хранения {{ section_link('audit-event') }}. Записи старше удаляются автоматически, итоги расходов остаются.
