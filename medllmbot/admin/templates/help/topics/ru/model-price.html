Как считается стоимость ответа

Claude API сообщает, сколько токенов ушло на каждый ответ. Бот умножает их на цены из этого раздела:

  • входные токены × цена Вход;
  • токены ответа × цена Выход;
  • токены записи в кэш × цена Запись в кэш;
  • токены чтения из кэша × цена Чтение из кэша.

Все цены — в долларах США за миллион токенов, как на странице цен Anthropic. Дробную часть можно отделять точкой или запятой: 0.15 и 0,15 — одно и то же. Цена — от 0 до 1000: больше не бывает, такое значение почти наверняка опечатка. Сумма сохраняется в записи {{ section_link('audit-event') }} и в итогах {{ section_link('usage-daily') }}.

Тарифы по длине запроса

У некоторых моделей длинные запросы дороже. Например, у claude-haiku-5-5 две строки: с От длины промпта = 0 и = 100001. Бот выбирает строку с наибольшим порогом, который не превышает длину запроса. У большинства моделей одна строка с порогом 0.

Когда править цены

  1. Перед сменой модели в {{ section_link('bot-config') }}: проверьте, что у новой модели есть строка с порогом 0, и добавьте её кнопкой + Создать: Цена модели, если нет.
  2. Anthropic изменил цены: обновите строку модели значком карандаша.

Актуальные цены — на странице цен Anthropic. Стартовые цены в базе взяты оттуда 10.11.2026.
