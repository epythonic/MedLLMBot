Что это за раздел

Это память бота. Каждый обычный обмен «вопрос клиента — ответ бота» сохраняется сюда. При следующем вопросе бот передаёт Claude последние сообщения этого клиента, и модель помнит, о чём шла речь. Сколько сообщений передавать, задаёт Глубина истории в {{ section_link('bot-config') }}.

Что сюда не попадает

  • Подозрительные сообщения и ответы, в которых модель пыталась раскрыть свои правила, — чтобы атака не накапливалась в памяти бота.
  • Слишком длинные сообщения, сообщения заблокированных клиентов и пропущенные из-за частоты.
  • Вопросы, на которые Claude не ответил из-за ошибки.

Всё это есть в {{ section_link('audit-event') }} — там записано каждое входящее сообщение.

Как прочитать диалог одного клиента

  1. Узнайте Chat ID клиента: он есть в {{ section_link('client') }}, в заявке и в журнале.
  2. В блоке Фильтры выберите у Chat ID условие Равно, введите номер и нажмите Применить фильтр.
  3. Сообщения идут новыми сверху. user — клиент, assistant — бот.

Чем переписка отличается от журнала

ПерепискаПамять бота для Claude. Только сообщения, прошедшие проверки, и только то, что получил клиент. Хранится бессрочно.
ЖурналВсе входящие сообщения: итог обработки, исходный ответ модели, токены и стоимость. Хранится столько дней, сколько указано в настройках.
{% call note("info", "Только чтение") %} Переписку нельзя изменить или удалить из админки: это исходные данные, на которые опирается бот. {% endcall %}
