What this section is

This is the bot's memory. Every ordinary “client question — bot answer” exchange is saved here. With the next question the bot passes this client's latest messages to Claude, and the model remembers what the conversation was about. How many messages are passed is set by History depth in {{ section_link('bot-config') }}.

What is not saved here

  • Suspicious messages and answers in which the model tried to reveal its rules, so that an attack does not build up in the bot's memory.
  • Messages that are too long, messages from blocked clients and messages skipped because the client wrote too often.
  • Questions Claude did not answer because of an error.

All of this is in {{ section_link('audit-event') }}: every incoming message is recorded there.

How to read one client's dialog

  1. Find the client's Chat ID: it is in {{ section_link('client') }}, in the lead and in the log.
  2. In the Filters panel, choose the Equals condition for Chat ID, enter the number and click Apply Filter.
  3. Messages are listed newest first. user is the client, assistant is the bot.

How chat history differs from the log

Chat historyThe bot's memory for Claude. Only messages that passed the checks, and only what the client received. Kept indefinitely.
LogAll incoming messages: processing outcome, the model's original answer, tokens and cost. Kept for as many days as set in the settings.
{% call note("info", "Read-only") %} Chat history cannot be edited or deleted from the admin panel: it is the source data the bot relies on. {% endcall %}
