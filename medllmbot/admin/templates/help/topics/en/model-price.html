How the cost of an answer is calculated

The Claude API reports how many tokens each answer used. The bot multiplies them by the prices in this section:

  • input tokens × the Input price;
  • answer tokens × the Output price;
  • cache write tokens × the Writing to cache price;
  • cache read tokens × the Reading from cache price.

All prices are in US dollars per million tokens, as on the Anthropic pricing page. The decimal part can be separated with a dot or a comma: 0.15 and 0,15 are the same. A price is from 0 to 1000: there are no higher prices, so such a value is almost certainly a typo. The amount is saved in the {{ section_link('audit-event') }} record and in the {{ section_link('usage-daily') }} totals.

Rates by request length

For some models, long requests cost more. For example, claude-haiku-5-5 has two rows: with From prompt length = 0 and = 100001. The bot picks the row with the highest threshold that does not exceed the request length. Most models have a single row with threshold 0.

When to edit prices

  1. Before changing the model in {{ section_link('bot-config') }}: check that the new model has a row with threshold 0, and add one with the + New Model price button if it does not.
  2. Anthropic changed its prices: update the model's row with the pencil icon.

Current prices are on the Anthropic pricing page. The starting prices in the database were taken from there on November 10, 2026.

{% call note("warning", "No price means understated costs") %} The price of a dated snapshot (claude-haiku-4-5-20251001) is taken from the row without the date (claude-haiku-4-5), but a different model version (claude-sonnet-5-6) does not inherit the price of claude-sonnet-5. If a model has no row, requests still go through, but their cost is not counted: they land in the “Unpriced” column in {{ section_link('usage-daily') }} and in the warning in {{ section_link('costs') }}. {% endcall %} {% call note("info", "Past requests are not recalculated") %} The cost is fixed at the moment of the answer. A new price applies only to subsequent requests. {% endcall %}
