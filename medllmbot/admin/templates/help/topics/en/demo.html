What this section is for

The section prepares the demo for a showing without access to the server. The buttons do the same as the seed --reset command:

  • Refresh the demo — return the current business to its initial state. The dates of the fictional chats count from the moment of the click, so {{ section_link('analytics') }} shows them for the past week again.
  • Switch to «…» — show the other business: the dental clinic or the electronics store. The bot profile, knowledge base, greeting and fictional clients change.

The browser asks for a confirmation before the reset. Afterwards the page shows which demo is now open.

What is deleted and what stays

  • Deleted: all clients, chats, leads, orders and log records — real ones too, if someone wrote to the bot during a showing. Your edits to the knowledge base, model prices and bot settings are reset as well.
  • Restored: the demo knowledge base, model prices, bot settings and the fictional clients with chats, leads in every status and a week of log.
  • Kept: {{ section_link('admin-user') }}, the totals in {{ section_link('usage-daily') }} and the daily spending limit from {{ section_link('bot-config') }}.
{% call note("warning", "Demo server only") %} The section is visible only when the server has ADMIN_DEMO_TOOLS=true. A real business's admin panel does not turn it on: one button would delete its clients and leads. {% endcall %}
