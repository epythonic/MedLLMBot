What is here

One row is one day and one model. The bot adds every Claude request to the row of its day at the same time as it writes the record to {{ section_link('audit-event') }}, so the totals always match the log.

  • Days are counted in UTC, as in Anthropic's invoices.
  • The rows contain no personal data and are not deleted together with old log records: from them you can calculate costs for any period.
  • The section is read-only — the totals are written by the bot.

The “Unpriced” column

How many requests that day were made with a model that has no price in {{ section_link('model-price') }}. The cost of such requests is not counted, so the day's total is understated. Add a price — the following requests will be counted, the past ones will remain without a cost.
