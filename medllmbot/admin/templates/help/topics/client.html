Откуда берутся клиенты

Клиент появляется здесь, как только впервые пишет боту. При каждом следующем сообщении бот обновляет его имя, username и время Последнего сообщения. Добавить или удалить клиента вручную нельзя: вместе с ним пропали бы переписка и заявки.

Как заблокировать клиента

  1. Найдите клиента: строка поиска ищет по Chat ID, username и имени. Chat ID удобно скопировать из {{ section_link('audit-event') }} или из заявки.
  2. Нажмите значок карандаша в строке клиента.
  3. Отметьте Заблокирован и нажмите Сохранить.

Быстрее — прямо из {{ section_link('audit-event') }}: на странице записи рядом с Chat ID есть кнопка Заблокировать клиента. Чтобы разблокировать, снимите отметку здесь или нажмите Разблокировать на странице записи журнала. Изменение действует со следующего сообщения клиента, перезапускать бота не нужно.

Что происходит с заблокированным клиентом

  • Бот молча перестаёт отвечать. Клиент не получает сообщения о блокировке.
  • Claude не вызывается, поэтому сообщения заблокированного клиента ничего не стоят.
  • Заявки из его сообщений не создаются.
  • Каждое сообщение всё равно попадает в {{ section_link('audit-event') }} с итогом «Клиент заблокирован» — видно, продолжает ли он писать.

Когда блокировать

Спам, оскорбления, повторяющиеся попытки взломать бота (в журнале много записей с отметкой Подозрительное). Фильтр Заблокирован справа показывает всех заблокированных.

{% call note("warning", "Одна подозрительная фраза — не повод") %} Детектор атак иногда ошибается. Прежде чем блокировать, откройте журнал клиента и убедитесь, что это не обычный вопрос, сформулированный необычно. {% endcall %}
